Install Oracle-12c-R2 on Windows

Oracle Download Address: https://edelivery.oracle.com/osdc/faces/SoftwareDelivery

Log in to your Oracle account

Open the Oracle download address connection, enter the Oracle account password login (if you do not have an account, please register an account first)

Download the installation package

  1. Enter the following text in the search box to search for installers
1

Oracle Database 12c Enterprise Edition
  1. Select a version of the installation package as follows
1

Oracle Database 12c Personal Edition 12.1.0.2.0

  1. Click on View Items in the upper right

  1. Select the corresponding installation environment and language, confirm and click Continue.

  1. Select Agree and click Continue

  1. Click to Download

  1. Open the downloaded downloader

  1. Select the download path and click Next

  1. Waiting for the download to complete

  1. Click on Open Destination when the download is complete

  1. Unzip the two downloaded zip archives (both separately, in the same directory)

Installing Oracle

  1. Open the directory you just unzipped and double-click to run setup

  1. No need to enter Email and no need for support, just tap Next and click Yes!

  1. Select Create and configure a database and click Next.

  1. Select the Desktop class and click Next.

  1. Select Create New Windows User, enter your username and password and click Next.

  1. Set the installation path, you can change the Global database name, enter the password, and other configuration items and click Next.

  1. Wait for the installer to check the installation environment

  1. Click Install

  1. Waiting for installation

  1. Click OK when the installation is complete (you can also click Password Management to configure passwords for other users).

Verify that the installation was successful

  1. The installation program will automatically install SQL Plus, open SQL Plus

  1. Enter the system username SYSTEM and the password as you configured it yourself

  1. Enter the following SQL to query the installed version
1

select * from product_component_version;
